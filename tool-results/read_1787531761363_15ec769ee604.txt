   234→#### **JavaScript для синхронизации скролла**
   235→```javascript
   236→// Добавляем в <script> внизу файла
   237→document.addEventListener('DOMContentLoaded', function() {

   244→      e.preventDefault();
   245→      const targetId = this.getAttribute('href').substring(1);
   246→      const targetItem = document.getElementById(targetId);
   247→      if (targetItem) {
   248→        targetItem.scrollIntoView({ behavior: 'smooth', block: 'start' });
   249→      }
   250→    });
   251→  });
   252→
   253→  // Подсветка активного пункта в sidebar
   254→  const observer = new IntersectionObserver((entries) => {
   255→    entries.forEach(entry => {
   256→      if (entry.isIntersecting) {
   257→        const id = entry.target.getAttribute('id');
   258→        sidebarLinks.forEach(link => {
   259→          link.classList.remove('active');
   260→          if (link.getAttribute('href') === `#${id}`) {
   261→            link.classList.add('active');
   262→          }
   263→        });
   264→      }
   265→    });
   266→  }, { threshold: 0.5 });
   267→
   268→  accordionItems.forEach(item => observer.observe(item));
   269→});

   901→### Для мобильных (≤ 768px)
   902→- Остаётся текущий дизайн. Это идеальный режим для «ловушки»: узкий экран, фокус на тексте, никаких отвлечений.
   903→
   904→### Для планшетов (768px – 1024px)
   905→- Увеличить `max-width` до 680px
   906→- Чуть крупнее шрифт (17-18px)
   907→- Более щедрые отступы между карточками
   908→
   909→### Для десктопа (≥ 1024px)
   910→- **Два режима на выбор пользователя:**
   911→  1. **«Режим чтения»** — одна колонка, но широкая (900px), крупный шрифт (18-19px), минимум отвлечений.
   912→  2. **«Режим обзора»** — две колонки с тезисами, где слева номер + заголовок, справа — содержание. Это позволяет бегло сканировать 33 тезиса.
   913→
   914→### Для большого экрана (≥ 1440px)
   915→- **Три колонки** для тезисов (но с возможностью переключиться на одну).
   916→- В «ловушке» (шаги 0-5) — **центрированный контент** с мягким ограничением ширины (макс 800-900px) для комфортного чтения.

  1588→## Вариант E — «читательская ширина + ловушка остаётся узкой»
  1589→
  1590→**Принцип:** экраны 0–5 (соматическая ловушка) остаются узкими; экран 6 (манифест) расширяется до читательской ширины.
  1591→
  1592→### 1. Ловушка (экраны 0–5): `max-width: 540px`
  1593→
  1594→Узкая колонка для ловушки — **это не баг, а соматический интерфейс**. Когда тело закрывает глаза и указывает рукой, узкая колонка фокусирует внимание. Thesis 31. Если бы ловушка была на весь десктоп, она бы рассеялась.
  1595→
  1596→```
  1597→540px осталось навсегда — для экранов 0-5
  1598→```
  1599→
  1600→### 2. Манифест (экран 6): `max-width: 740px` для body, `840px` для epistemic-gap
  1601→
  1602→**740px — не случайное число.** Это ширина, при которой абзац 17-18px шрифта содержит 60-80 символов в строке. Это типографский оптимум, к которому пришли New Yorker, The Atlantic, Medium, Are.na, газета «Коммерсантъ» — все серьёзные лонгриды. Доказано в исследованиях чтения (Dyson & Haselgrove, 2001; Bayard & Tijus, 2013): при 60-80 символах в строке максимизируется понимание и минимизируется усталость глаз.
  1603→
  1604→**Почему не 1000px (как ты предложил в варианте A)?** Потому что при 1000px абзац 18px шрифта содержит 110-120 символов в строке — глазу приходится слишком далеко прыгать от конца одной строки к началу следующей. Comprehension падает. Это визуально «богаче», но когнитивно беднее.
  1605→
  1606→Epistemic-gap (mono, 10-12px) терпит более широкую строку — поэтому ему можно 820-840px.
  1607→
  1608→### 3. Жидкая типографика через `clamp()`
  1609→
  1610→Вместо скачков по media queries — плавная интерполяция:
  1611→
  1612→```css
  1613→.accordion-content {
  1614→  font-size: clamp(16px, 0.4vw + 14.5px, 18px);
  1615→  line-height: clamp(1.75, 1.78, 1.85);
  1616→  max-width: 740px;
  1617→}
  1618→
  1619→.epistemic-gap {
  1620→  font-size: clamp(10.5px, 0.2vw + 10px, 12px);
  1621→  max-width: 820px;
  1622→}
  1623→
  1624→.screen-manifest .accordion {
  1625→  max-width: min(840px, calc(100vw - 48px));
  1626→  margin: 0 auto;
  1627→}
  1628→```
  1629→
  1630→### 4. Одно необязательное UX-улучшение, не нарушающее тезис 13
  1631→
  1632→Маленький плавающий индекс в правом нижнем углу — **цифры 01-33**, кликабельные, `opacity: 0.3`, `:hover opacity: 1`.   1637→- Не претендует на роль оглавления — это «быстрая навигация для повторного входа», а не «справочник»
