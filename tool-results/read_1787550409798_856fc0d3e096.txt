   422→   481→   481→  1445→### Recipe R5: Clean White (Academic)
   423→   482→   482→  1446→
   424→   483→   483→  1447→**Visual:** Pure white background + school name + centered title + 2-column meta info table with underlines + footer
   425→   484→   484→  1448→**Use case:** academic thesis, standards documents
   426→   485→   485→  1449→**Architecture:** 16838 outer wrapper (white fill, invisible) + cell margins for page margin simulation. No top/bottom decorative lines.
   427→   486→   486→  1450→
   428→   487→   487→  1451→**Meta info table rules (cross-engine safe):**
   429→   488→   488→  1452→- 2-column table: label + value, **percentage widths only** (`WidthType.PERCENTAGE`)
   430→   489→   489→  1453→- **Table width is adaptive:** 55–75% of page, calculated by `calcR5MetaLayout()`. Table centered via `alignment: CENTER`.
   431→   490→   490→  1454→- **Label column:** adaptive 25–45% of table, **LEFT aligned**, plain text with "：" appended. NO full-width space padding, NO right-alignment.
   432→   491→   491→  1455→- **Label column borders:** none (no bottom border on label cells).
   433→   492→   492→  1456→- **Value column:** remaining %, **LEFT aligned**, `bottom: single sz=4` border = fixed-length underline (consistent length for all rows regardless of text).
   434→   493→   493→  1457→- No left/right/top borders on either column.
   435→   494→   494→  1458→- ⚠️ Do NOT use DXA widths, full-width space padding (`\u3000`), spacer columns, or tab stops — WPS renders them inconsistently.
   436→   495→   495→  1459→- ⚠️ Do NOT use `margins.top` on the wrapper cell — use `spacing.before` on first paragraph instead.
   437→   496→   496→  1460→
   438→   497→   497→  1461→**Known limitation:** When meta lines ≥ 6 AND title has 3 lines, MS Office may render content slightly taller than WPS, potentially clipping the footer line. Mitigate by reducing `midSpacing` or using a smaller title font.
   439→   498→   498→  1462→
   440→   499→   499→  1463→```js
   441→   500→   500→  1464→// ── Width-aware title layout (handles mixed Chinese + English) ──
   442→   501→   501→  1465→function estimateTextWidth(text, pt) {
   443→   502→   502→  1466→  let width = 0;
   444→   503→   503→  1467→  for (const ch of text) {
   445→   504→   504→  1468→    const code = ch.codePointAt(0);
   446→   505→   505→  1469→    const isCJK = (code >= 0x4E00 && code <= 0x9FFF) || (code >= 0x3400 && code <= 0x4DBF) ||
   447→   506→   506→  1470→      (code >= 0x3000 && code <= 0x303F) || (code >= 0xFF00 && code <= 0xFFEF) ||
   448→   507→   507→  1471→      (code >= 0x2E80 && code <= 0x2EFF);
   449→   508→   508→  1472→    width += isCJK ? pt * 20 : pt * 11; // CJK: full-width, Latin: ~55% width
   450→   509→   509→  1473→  }
   451→   510→   510→  1474→  return width;
   452→   511→   511→  1475→}
   453→   512→   512→  1476→// Use estimateTextWidth() in calcTitleLayout() instead of simple char count
   454→   513→   513→  1477→// to prevent mid-word breaks in mixed Chinese+English titles like "基于Transformer架构的..."
   455→   514→   514→  1478→
   456→   515→   515→  1479→// ── Meta info table ──
   457→   516→   516→  1480→
   458→   517→   517→  1481→// Calculate adaptive table and label column percentage based on longest label.
   459→   518→   518→  1482→// Returns { tablePct, labelPct } — both as percentages.
   460→   519→   519→  1483→// Uses ONLY WidthType.PERCENTAGE for cross-engine compatibility (MS Office + WPS).
   461→   520→   520→  1484→function calcR5MetaLayout(metaEntries, fontPt = 12) {
   462→   521→   521→  1485→  const maxLabelLen = Math.max(...metaEntries.map(e => [...e.label].length));
   463→   522→   522→  1486→  // Label needs: maxLabelLen chars + "：" + 1 char padding
   464→   523→   523→  1487→  const labelNeedTw = (maxLabelLen + 2) * fontPt * 20;
   465→   524→   524→  1488→  // Value column: fixed ~5000tw for consistent underline length
   466→   525→   525→  1489→  const valueNeedTw = 5000;
   467→   526→   526→  1490→  const totalNeedTw = labelNeedTw + valueNeedTw;
   468→   527→   527→  1491→  // Table width as % of page (11906tw), clamped to 55–75%
   469→   528→   528→  1492→  const tablePct = Math.min(75, Math.max(55, Math.ceil(totalNeedTw / 11906 * 100)));
   470→   529→   529→  1493→  // Label % within the table, clamped to 25–45%
   471→   530→   530→  1494→  const rawLabelPct = Math.ceil(labelNeedTw / (tablePct / 100 * 11906) * 100);
   472→   531→   531→  1495→  return { tablePct, labelPct: Math.max(25, Math.min(45, rawLabelPct)) };
   473→   532→   532→  1496→}
   474→   533→   533→  1497→
   475→   534→   534→  1498→// Build R5 academic cover meta info table.
   476→   535→   535→  1499→// ⚠️ CRITICAL cross-engine rules:
   477→   536→   536→  1500→//   - Table width: WidthType.PERCENTAGE (NOT DXA — WPS breaks with DXA)
   478→   537→   537→  1501→//   - Column widths: WidthType.PERCENTAGE
   479→   538→   538→  1502→//   - Label column: LEFT aligned, plain text (NO full-width space padding)
   480→   539→   539→  1503→//   - Value column: LEFT aligned, bottom border = fixed-length underline
   481→   540→   540→  1504→//   - Table alignment: CENTER (visually centered on page)
   482→   541→   541→  1505→function buildR5MetaTable(metaEntries) {
   483→   542→   542→  1506→  // metaEntries: [{ label: "学院", value: "计算机科学与技术学院" }, ...]

   485→   544→   544→  1508→  const valuePct = 100 - labelPct;

   487→   546→   546→  1510→

   505→   564→   564→  1528→      new TableCell({

   520→   579→   579→  1543→
   521→   580→   580→  1544→  return new Table({

   524→   583→   583→  1547→    layout: TableLayoutType.FIXED,
   525→   584→   584→  1548→    borders: allNoBorders,
   526→   585→   585→  1549→    rows,
   527→   586→   586→  1550→  });
   528→   587→   587→  1551→}
   529→   588→   588→  1552→
   530→   589→   589→  1553→// ⚠️ MANDATORY: Cover section must use margin: 0. See "Cover Section Non-Negotiables" above.

   638→   697→   697→  1661→  const p = (s, i) => parseInt(s.replace("#","").slice(i, i+2), 16);
   639→   698→   698→  1662→  const mix = (c1, c2) => Math.round(c1 + (c2 - c1) * ratio);

   699→   758→   758→  1722→1. **Anti-overlap**: If >6 x-axis labels, rotate 45° (`plt.xticks(rotation=45, ha='right')`)
   700→   759→   759→  1723→2. **Anti-stretch**: Always set figure size explicitly (`fig, ax = plt.subplots(figsize=(10, 6))`)
   701→   760→   760→  1724→3. **Aspect ratio (CRITICAL)**: When embedding in docx, MUST read actual image dimensions and calculate height proportionally. NEVER hardcode both width and height — pie charts become ellipses, radar charts become diamonds.
   702→   761→   761→  1725→   ```js
   703→   762→   762→  1726→   const sizeOf = require("image-size");
   704→   763→   763→  1727→   const dims = sizeOf(chartBuffer);
   705→   764→   764→  1728→   const displayWidth = 500;
   706→   765→   765→  1729→   const displayHeight = Math.round(displayWidth * (dims.height / dims.width));
   707→   766→   766→  1730→   // transformation: { width: displayWidth, height: displayHeight }
   708→   767→   767→  1731→   ```
   709→   768→   768→  1732→4. **DPI**: Save at 200+ DPI (`plt.savefig("chart.png", dpi=200, bbox_inches="tight")`)
   710→   769→   769→  1733→5. **Colors**: Use palette accent color for primary data series
   711→   770→   770→  1734→6. **Legend**: Place outside plot area if >4 series
   712→   771→   771→  1735→7. **Square charts**: Pie and radar charts MUST use `figsize=(8, 8)` (equal width/height) to preserve circular/radial shape
   713→   772→   772→  1736→7. **Grid**: Light gray grid (`ax.grid(True, alpha=0.3)`)
