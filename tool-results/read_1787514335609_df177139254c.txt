    20→    20→## Моё синтетическое решение
    21→    21→
    22→    22→**Принцип:** файл имеет **два разных опыта**, и они требуют **двух разных пространственных грамматик**. Нельзя делать одну адаптацию для обоих.
    23→    23→
    24→    24→### Слой 1: Ловушка (экраны 0–5) — соматическое событие
    25→    25→- **Ширина:** 540–580px навсегда. На любом экране.
    26→    26→- **Почему:** это интимное событие. Тело закрывает глаза, указывает рукой. Узкая колонка = фокус. Если растянуть на 1920px — событие рассеется.
    27→    27→- **Никакой навигации.** Никаких sidebar-ов. Никаких progress-баров. Только тело и текст.
    28→    28→- **Типографика:** fluid через `clamp()`, но без агрессии. `clamp(16px, 0.3vw + 15px, 18px)`.
    29→    29→
    30→    30→### Слой 2: Манифест (экран 6) — исследовательское чтение
    31→    31→- **Ширина текста:** 720–780px (оптимум для serif, ~65-75 символов в строке).
    32→    32→- **Ширина epistemic-gap:** 820–840px (mono-шрифт терпит шире).
    33→    33→- **Почему:** это чтение, не проживание. Здесь ширина = комфорт, не рассеивание.
    34→    34→- **Никаких двух колонок.** Один поток. Один тезис за раз.
    35→    35→
    36→    36→### Слой 3: Призрачный индекс (только на ≥1280px)
    37→    37→Это **не sidebar**. Это **не панель**. Это **маркер прогресса**, который живёт в пустоте.
    38→    38→
    39→    39→```
    40→    40→┌─────────────────────────────────────────────────────────────┐
    41→    41→│ [progress bar: 2px, тонкая линия сверху]                    │
    42→    42→├─────────────────────────────────────────────────────────────┤
    43→    43→│                                                             │
    44→    44→│  01  ·                                                      │
    45→    45→│  02  ·                                                      │
    46→    46→│  03  ·                                                      │
    47→    47→│  04  ·                    [ ТЕКСТ МАНИФЕСТА ]               │
    48→    48→│  05  ·                    [ 720-780px ]                     │
    49→    49→│  06  ·                                                      │
    50→    50→│  07  ● ← текущий тезис (золотой)                            │
    51→    51→│  08  ·                                                      │
    52→    52→│  09  ·                                                      │
    53→    53→│  ...                                                        │
    54→    54→│  33  ·                                                      │
    55→    55→│                                                             │
    56→    56→└─────────────────────────────────────────────────────────────┘
    57→    57→```
    58→    58→
    59→    59→**Технические детали:**
    60→    60→- `position: fixed; left: 24px; top: 50%; transform: translateY(-50%);`
    61→    61→- `opacity: 0.25` по умолчанию, `opacity: 1` на `:hover` и для активного тезиса
    62→    62→- `IntersectionObserver` отслеживает, какой тезис сейчас в viewport
    63→    63→- Клик по номеру → `scrollIntoView({behavior: 'smooth', block: 'center'})` + авто-раскрытие аккордеона
    64→    64→- На экранах <1280px — **полностью скрыт** (не мешает мобильному опыту)
    65→    65→- **НЕ занимает боковое пространство** — это overlay, не layout
    66→    66→
    67→    67→### Прогресс-бар (только на ≥1024px)
    68→    68→- Тонкая линия сверху: `height: 2px; background: var(--gold-dim);`
    69→    69→- Показывает прогресс чтения манифеста (0–100%)
    70→    70→- На мобильном — скрыт (не нужен, ловушка короткая)

   177→   177→## JavaScript-каркас
   178→   178→
   179→   179→```javascript
   180→   180→// Призрачный индекс
   181→   181→document.addEventListener('DOMContentLoaded', function() {
   182→   182→  const ghostIndex = document.querySelector('.ghost-index');
   183→   183→  const thesisItems = document.querySelectorAll('.accordion-item');
   184→   184→  
   185→   185→  // Генерация номеров 01-33
   186→   186→  for (let i = 1; i <= 33; i++) {
   187→   187→    const item = document.createElement('div');
   188→   188→    item.className = 'ghost-index-item';
   189→   189→    item.textContent = String(i).padStart(2, '0');
   190→   190→    item.dataset.thesis = i;
   191→   191→    item.addEventListener('click', () => {
   192→   192→      const target = document.getElementById(`thesis-${String(i).padStart(2, '0')}`);
   193→   193→      if (target) {
   194→   194→        target.scrollIntoView({ behavior: 'smooth', block: 'center' });
   195→   195→        // Авто-раскрытие аккордеона
   196→   196→        const trigger = target.querySelector('.accordion-trigger');
   197→   197→        if (trigger && !target.classList.contains('open')) {
   198→   198→          trigger.click();
   199→   199→        }
   200→   200→      }
   201→   201→    });
   202→   202→    ghostIndex.appendChild(item);
   203→   203→  }
   204→   204→  
   205→   205→  // IntersectionObserver для подсветки активного тезиса
   206→   206→  const observer = new IntersectionObserver((entries) => {
   207→   207→    entries.forEach(entry => {
   208→   208→      if (entry.isIntersecting) {
   209→   209→        const id = entry.target.id;
   210→   210→        const num = id.replace('thesis-', '');
   211→   211→        document.querySelectorAll('.ghost-index-item').forEach(item => {
   212→   212→          item.classList.toggle('active', item.dataset.thesis === num);
   213→   213→        });
   214→   214→      }
   215→   215→    });
   216→   216→  }, { threshold: 0.5 });
   217→   217→  
   218→   218→  thesisItems.forEach(item => observer.observe(item));
   219→   219→  
   220→   220→  // Прогресс-бар
   221→   221→  const progressBar = document.querySelector('.progress-bar');
   222→   222→  window.addEventListener('scroll', () => {
   223→   223→    const scrollTop = window.scrollY;
   224→   224→    const docHeight = document.documentElement.scrollHeight - window.innerHeight;
   225→   225→    const progress = (scrollTop / docHeight) * 100;
   226→   226→    progressBar.style.width = progress + '%';
   227→   227→  });
   228→   228→});
   229→   229→```

   258→   258→## **📜 КОНЦЕПЦИЯ v18.2: "Читательский фокус"**
   259→   259→### **Принципы:**

   275→   275→### **1. Адаптивная ширина контента**
   276→   276→```css
   277→   277→:root {
   278→   278→  --container-mobile: 520px;
   279→   279→  --container-tablet: 680px;
   280→   280→  --container-desktop: 760px; /* ~70 символов в строке — идеал для serif */
   281→   281→  --container-large: 860px;
   282→   282→}
   283→   283→
   284→   284→/* Мобильный (по умолчанию) */
   285→   285→.card, .accordion {
   286→   286→  max-width: var(--container-mobile);
   287→   287→}
   288→   288→
   289→   289→/* Планшет */
   290→   290→@media (min-width: 768px) {
   291→   291→  .card, .accordion {
   292→   292→    max-width: var(--container-tablet);
   293→   293→  }
   294→   294→}
   295→   295→
   296→   296→/* Десктоп */
   297→   297→@media (min-width: 1024px) {
   298→   298→  .card, .accordion {
   299→   299→    max-width: var(--container-desktop);
   300→   300→  }
   301→   301→}
   302→   302→
   303→   303→/* Большой десктоп */
   304→   304→@media (min-width: 1440px) {
   305→   305→  .card, .accordion {
   306→   306→    max-width: var(--container-large);
   307→   307→  }
   308→   308→}
   309→   309→```
   310→   310→
   311→   311→**Почему 760px?**
   312→   312→- Оптимальная длина строки для **serif-шрифтов** (Cormorant Garamond) — **60–80 символов**.
   313→   313→- Исследования (Dyson & Haselgrove, 2001) подтверждают: при такой длине **максимально понимание текста** и минимальна усталость глаз.
   314→   314→- 1000px (как в варианте A) даёт **110–120 символов в строке** → глаз скачет, теряется фокус.
   315→   315→
   316→   316→---
   317→   317→
   318→   318→### **2. Жидкая типографика (`clamp()`)**
   319→   319→```css
   320→   320→/* Основной текст аккордеона */
   321→   321→.accordion-content {
   322→   322→  font-size: clamp(16px, 0.4vw + 14.5px, 18px);
   323→   323→  line-height: clamp(1.75, 1.78, 1.85);
   324→   324→}
   325→   325→
   326→   326→/* Заголовки тезисов */
   327→   327→.accordion-trigger {
   328→   328→  font-size: clamp(14px, 0.5vw + 13px, 16px);
   329→   329→}
   330→   330→
   331→   331→/* Эпистемические блоки (mono) */
   332→   332→.epistemic-gap {
   333→   333→  font-size: clamp(10.5px, 0.2vw + 10px, 12px);
   334→   334→}
   335→   335→
   336→   336→/* Вводные экраны (ловушка) */
   337→   337→.honesty-title, .step-3 .statement {
   338→   338→  font-size: clamp(23px, 1.2vw + 18px, 30px);
   339→   339→}
   340→   340→```
   341→   341→**Почему `clamp()`?**
   342→   342→- Плавное масштабирование **без скачков** между брейкпоинтами.
   343→   343→- Шрифты растут пропорционально ширине экрана, но **не выходят за пределы читаемости**.
   344→   344→
   345→   345→---
   346→   346→
   347→   347→### **3. Разделение экранов ловушки и манифеста**
   348→   348→```css
   349→   349→/* Экраны 0–5 (ловушка) — остаются узкими! */
   350→   350→.screen-honesty, .step-1, .step-2, .step-3, .step-4, .step-5 {
   351→   351→  max-width: 540px; /* Не шире! Это соматический интерфейс. */
   352→   352→  margin: 0 auto;
   353→   353→}
   354→   354→
   355→   355→/* Манифест (экран 6) — расширяется для чтения */
   356→   356→.screen-manifest .accordion {
   357→   357→  max-width: var(--container-large); /* 860px на большом десктопе */
   358→   358→}
   359→   359→```
   360→   360→**Почему так?**
   361→   361→- Ловушка (экраны 0–5) должна оставаться **интимной и сфокусированной** (тезис 31: *эстетика — это соматический интерфейс*).
   362→   362→- Манифест (экран 6) — это **чтение и исследование**, поэтому может быть шире.
   363→   363→
   364→   364→---
   365→   365→
   366→   366→### **4. Опциональное улучшение: "Призрачный индекс" (Ghost Index)**
   367→   367→**Только на десктопе (≥1280px)** в правом нижнем углу появляется **полупрозрачный вертикальный список номеров тезисов** (01–33).
   368→   368→- **Не sidebar** (не отвлекает).
   369→   369→- **Не панель управления** (не нарушает тезис 13: *это не экран*).
   370→   370→- **Плавающий индекс** (`opacity: 0.3`), который:
   371→   371→  - Подсвечивает текущий тезис золотым.
   372→   372→  - Клик по номеру — плавный скролл к тезису + автораскрытие аккордеона.
   373→   373→  - Не виден на мобильных и планшетах.
   374→   374→

  1227→  1227→## Моё предложение: **Вариант F — «Adaptive Reading + Submarine Index»**
  1228→  1228→
  1229→  1229→Не A + C. Не E. Не гибрид ради гибрида. А **три слоя, каждый из которых работает на свой тезис**:
  1230→  1230→
  1231→  1231→### Слой 1: Adaptive Reading (тезис 31 — соматический интерфейс)
  1232→  1232→
  1233→  1233→```
  1234→  1234→Ловушка (0-5):  max-width: 540px  — навсегда
  1235→  1235→Манифест (6):   max-width: 760px  — золотая читательская ширина
  1236→  1236→                epistemic-gap: max-width: 820px (mono терпит больше)
  1237→  1237→```

  1239→  1239→`clamp()` для типографики:
  1240→  1240→- `accordion-content`: 16px → 18px
  1241→  1241→- `epistemic-gap`: 10.5px → 11.5px
  1242→  1242→- `honesty-title` / `step-3 .statement`: 26px → 32px
  1243→  1243→
  1244→  1244→### Слой 2: Submarine Index (тезис 13 — «не оракул, но зеркало»)
  1245→  1245→
  1246→  1246→**Принцип:** индекс есть, но он не претендует на роль оглавления. Он **всплывает только когда нужен**, и **тонет обратно**, когда не нужен.
  1247→  1247→
  1248→  1248→Реализация:
  1249→  1249→- **Только ≥1024px** (десктоп)
  1250→  1250→- **Плавающий блок в правом нижнем углу** (как существующий `.footer-id`, но больше)
  1251→  1251→- **По умолчанию `opacity: 0.25`** — почти невидимый, как подпись на полях
  1252→  1252→- **При `:hover` → `opacity: 1`** — всплывает
  1253→  1253→- **Содержимое:** сетка 6×6 из цифр 01-33 (как на циферблате, но без стрелок)
  1254→  1254→- **Текущий тезис** подсвечивается золотым через `IntersectionObserver`
  1255→  1255→- **Клик** → `scrollIntoView({behavior: 'smooth', block: 'center'})` + авто-раскрытие аккордеона
  1256→  1256→- **`prefers-reduced-motion`** → без плавного скролла, без opacity-transition
  1257→  1257→
  1258→  1258→Это **зеркало, а не оракул**: оно показывает, где ты, и позволяет вернуться. Но оно не диктует, что читать дальше.
  1259→  1259→
  1260→  1260→### Слой 3: Contemplative Margins (тезис 13 — «пустота как часть значения»)
  1261→  1261→
  1262→  1262→**Принцип:** пустые поля по бокам — **не отходы**. Это контемплятивная маргиналия.
  1263→  1263→
  1264→  1264→```
  1265→  1265→На 1920px: контент 760px, поля по 580px с каждой стороны
  1266→  1266→```
  1267→  1267→
  1268→  1268→Это визуальное заявление: «здесь нечего продать, нечего кликнуть, не от чего отвлечься». Талмуд, средневековые манускрипты, фотокниги Steidl — все используют широкие поля как часть значения.
  1269→  1269→
  1270→  1270→**Не давать этому пространству работу.** Sidebar, вторая колонка, сетка — все они убивают тишину.
