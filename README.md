Семиэпохальное историко-лингвистическое эссе, построенное как **детерминированный конечный автомат**.

**Читать:** https://rtynbirf.github.io/yazyk-skvoz-epohi/

## Идея

Документ `M = (Q, Σ, δ, q₀, F)`:

- **Q** — десять состояний: обложка, семь эпох (Античность → XXI век), послесловие, автомат;
- **Σ** — символы: `scroll, next, prev, top, end, globe, shadow` (ваши действия);
- **δ** — таблица переходов (показана в состоянии q₉);
- **q₀** — обложка; **F = {q₉}** — акцептирующее состояние.

Прочитаете все семь эпох — машина объявит: **ω ∈ L(M), язык принят**.

Историческая ирония: классификацию конечных автоматов дал Хомский — герой эпохи VI. Регулярные языки (тип-3 его иерархии) — это в точности языки конечных автоматов. Дом, рассказывающий историю языка, сам является формальным языком.

## Что внутри

- **7 эпох × 7 кириллических шрифтов** — каждый стилистически соответствует эпохе: Cormorant (Античность), Vollkorn (Средневековье), EB Garamond (Новое время), Old Standard TT (Просвещение), Playfair Display (XIX век), PT Serif (XX век), Inter (XXI век).
- **3 слоя истории** — Канон / +Глобус (неевропейские параллели: Панини, Сюй Шэнь, Хильдегарда Бингенская, Ибн Рушд, Уильям Джонс, Мотоори Норинага, Бодуэн де Куртенэ, Выготский, Рош, Таннен) / +Тень (язык и власть: софисты и рабство, латынь и инквизиция, сожжение Доле, Эмский указ, ALPAC, авторские права эпохи LLM).
- **Живая машина** — лента переходов δ(qᵢ, a) → qⱼ в углу, δ-таблица и SVG-диаграмма состояний.
- **WCAG 2.2 AA** — контраст всех пар ≥ 5.4:1, фокус 2px/≥3:1, `prefers-reduced-motion`, полная работа без JavaScript.

## Карта клавиш

| Клавиша | Действие |
|---|---|
| `→` / `←` | следующее / предыдущее состояние |
| `1–7` | эпохи · `0` обложка · `8` послесловие · `9` автомат |
| `G` / `T` | добавить / убрать слой истории |
| `Home` / `End` | q₀ / q₉ |

## Ленты переходов

Лента — не метафора: в документе она и есть «лента переходов δ». Подписка — чтение той же машины со стороны.

- [δ-лента по-русски (RSS 2.0)](https://rtynbirf.github.io/yazyk-skvoz-epohi/feed.xml) — десять состояний q₀…q₉;
- [δ-лента latine (RSS 2.0)](https://rtynbirf.github.io/yazyk-skvoz-epohi/feed-la.xml) — вторая версия, *Lingua per Aetates*.

Обе ленты ссылаются друг на друга (`atom:link rel=alternate hreflang`), а документ объявляет их в `<head>`.

## Автоматика дома

Дом не просто изображает автомат — он им обслуживается. Ни одного внешнего сервиса:

- **Страж дома** (`.github/workflows/guard.yml`) — приёмка каждого изменения: Nu HTML Checker (vnu), XML-ленты, инварианты артефактов. Сам страж — ДКА из `scripts/check.py`: десять состояний, символы — артефакты дома, вердикт fail-closed: `ω ∈ L(G)`.
- **Счётчик-автомат** (`.github/workflows/traffic.yml`) — ежедневно в 03:37 UTC спрашивает GitHub traffic API и дописывает историю по дням в `traffic.json`; сумма истории показывается в подвале документа («визитов за всё время наблюдения»). Без cookies, без скриптов третьих сторон, ничего не хранит о читателе — считает только сам GitHub.
- **404** — единственное недетерминированное место дома: страница `δ(q, a) → ∅` с возвратом в q₀.
